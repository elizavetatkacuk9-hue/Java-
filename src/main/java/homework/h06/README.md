Відповідь: git log показує історію комітів (хто, коли та з яким повідомленням зберіг зміни). git diff показує конкретну різницю та зміни в коді між файлами, гілками або станами. Завдання 3: Відкрита дискусія Як комп'ютер зберігає літеру, якщо вміє зберігати тільки числа? Комп'ютер використовує таблиці кодування (ASCII, Unicode), де кожній літері відповідає числовий код у двійковій системі. Чому 'A' і "A" — це різні речі? 'A' це символ типу char (числовий код у пам'яті), а "A" це об'єкт типу String (рядок із додатковими даними та методами). Чим порожній рядок відрізняється від відсутнього? Порожній рядок ("") це існуючий об'єкт довжиною 0, а відсутній рядок (null) це відсутність посилання на об'єкт. Звідки беруться «кракозябри» замість тексту? Вони виникають при відкритті файлу в іншій кодувальній таблиці, ніж та, в якій його зберегли (наприклад, UTF-8 замість Windows-1251). Скільки літер у смайлику 🩩? Для людини це 1 символ, але в Java та кодуванні UTF-16 він складається з двох елементів char (сурогатна пара), тому довжина дорівнює 2. Чому слово «Привіт» у файлі важить більше, ніж «Hello»? У кодуванні UTF-8 латинські літери займають по 1 байту (Hello = 5 байтів), а кириличні літери — по 2 байти (Привіт = 12 байтів).

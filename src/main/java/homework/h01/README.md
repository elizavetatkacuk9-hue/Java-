Завдання 2: Відповіді на запитання щодо Git
Питання: У чому різниця між командами git log та git diff?
Відповідь: git log показує історію комітів (хто, коли та з яким повідомленням зберіг зміни). git diff показує конкретну різницю та зміни в коді між файлами, гілками або станами.
Завдання 3: Відкрита дискусія
Що таке програма?
Програма — це набір інструкцій для комп'ютера, написаний мовою програмування, який виконує певну задачу.
Що таке алгоритм?
Алгоритм — це чітка послідовність кроків і правил для розв'язання конкретної задачі за скінченний час.
Навіщо потрібно так багато мов програмування?
Різні мови створюються під різні задачі та сфери (наприклад, Java — для бекенду та корпоративних систем, Python — для аналізу даних та ШІ, C++ — для високопродуктивних систем і ігор).
Дайте визначення алгоритму приготування борщу:
Підготувати та помити інгредієнти (м'ясо, буряк, картоплю, капусту, цибулю, моркву).
Зварити м'ясний бульйон.
Нарізати овочі та зробити засмажку з цибулі, моркви та буряка.
Додати в бульйон картоплю та капусту, потім засмажку.
Посолити, додати спецїї та проварити до готовності.
Дайте визначення алгоритму зав'язування шнурків:
Схрестити два шнурки й продіти один під інший, затягнувши базовий вузол.
Зробити петлю з кожного шнурка.
Схрестити петлі, продіти одну петлю в отвір, що утворився, і затягнути.
Чи є інструкція із зав'язування шнурків програмою?
Ні, це алгоритм для людини. Програмою вона стане тоді, коли буде записана мовою, зрозумілою виконавчому пристрою (наприклад, роботу).

1.Чому комп’ютер рахує двійками, а не десятками, як ми?
Електронним компонентам (транзисторам) надійніше та простіше розрізняти лише два фізичні стани: наявність сигналу (висока напруга або логічна «1») та його відсутність (низька напруга або логічний «0»). Це мінімізує помилки обчислень і максимально спрощує схемотехніку.  2.Що таке біт і чому саме вісім бітів назвали байтом?
Бит — це мінімальна одиниця вимірювання інформації, яка може набувати значення 0 або 1. Вісім бітів об’єднали в байт, оскільки 2^8 = 256 можливих комбінацій виявилося ідеально достатньо для кодування стандартного набору символів: латинського алфавіту, цифр, розділових знаків та базових управлінських знаків (таблиця ASCII).  3.Як записати від’ємне число, якщо в пам’яті є лише нулі й одиниці?
Для цього використовується додатковий код (Two’s Complement). Старший (найлівіший) біт виділяється під знак (0 — додатне число, 1 — від’ємне). Щоб отримати від’ємне число, двійковий код додатного числа інвертують (міняють нулі на одиниці, а одиниці на нулі) і додають до результату одиницю.  4.Чому виникає переפoвнення і як з ним боротися?
Переповнення трапляється тоді, коли результат арифметичної операції стає більшим за максимальне значення, яке може вмістити виділена для цього розрядність пам’яті (наприклад, тип даних ⁠int⁠).  5.Як боротися: використовувати типи даних з більшим діапазоном (наприклад, ⁠long⁠ замість ⁠int⁠), або застосовувати перевірки граничних значень перед виконанням обчислень. 6.Чому в старих іграх максимум золота — рівно 2 147 483 647?
Це максимальне додатне число, яке можна зберегти у знаковому 32-бітному цілому типі даних (2^{31} - 1), оскільки старший біт зарезервований під знак «плюс» або «мінуc».  7.Чому комп’ютер вважає, що 7 / 2 = 3?
Оскільки використовується цілочисельне ділення (тип даних ⁠int⁠), комп’ютер ділить ціле на ціле і записує результат у той самий цілочисельний формат, просто відкидаючи дробову частину без заокруглення. Щоб отримати дробовий результат (3.5), хоча б одне з чисел слід записати як число з плаваючою точкою, наприклад ⁠7.0 / 2⁠.

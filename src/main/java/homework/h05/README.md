Відповідь: git log показує історію комітів (хто, коли та з яким повідомленням зберіг зміни). git diff показує конкретну різницю та зміни в коді між файлами, гілками або станами. Завдання 3: Відкрита дискусія Навіщо масив, якщо можна завести сто окремих змінних? Масив дозволяє зберігати безліч однотипних даних в одній структурі, зручно обробляти їх у циклах та передавати в функції без створення сотень змінних вручну. Що таке індекс і чому програма падає з «index out of bounds»? Індекс — це порядковий номер елемента в масиві. Помилка виникає, коли ми намагаємося звернутися до елемента за індексом, якого не існує (наприклад, від'ємний індекс або індекс, більший чи рівний довжині масиву). Чому розмір звичайного масиву не можна змінити після створення? У пам'яті комп'ютера під масив виділяється суцільний блок фіксованого розміру; щоб збільшити масив, потрібно створити новий масив більшого розміру та скопіювати туди всі дані. Чому прохід по рядку 2D-масиву швидший за прохід по колонці? Елементи одного рядка розташовані в операційній пам'яті послідовно один за одним, тому процесор зчитує їх набагато швидше завдяки кешуванню (spatial locality). Чому масиви нумеруються з нуля, а не з одиниці? Індекс показує зсув (offset) від початку блоку пам'яті, виділеного під масив; для першого елемента зсув дорівнює 0. Чому додати елемент у кінець масиву дешево, а на початок — дорого? Додати в кінець можна одразу, якщо є вільне місце, а при додаванні на початок доводиться зсувати всі існуючі елементи масиву вправо на одну позицію.

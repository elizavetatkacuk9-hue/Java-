1.Як знайти найбільше число в масиві?
Потрібно взяти перший елемент масиву як початковий максимум, а потім пройти циклом по всіх інших елементах. Якщо зустрічається елемент, більший за поточний максимум, оновити його значення. 2.Чому майже кожна задача на масив починається з одного проходу циклом?
Тому що дані в масиві розташовані послідовно в пам’яті, і для їх аналізу, пошуку чи перетворення зазвичай потрібно переглянути кожен елемент хоча б один раз (лінійна складність). 3.Що має робити код, якщо масив порожній?
Код повинен містити перевірку (guard clause) на порожність масиву (наприклад, перевірку довжини на рівність нулю), щоб уникнути винятків на кшталт ⁠IndexOutOfBoundsException⁠, і повернути безпечне значення за замовчуванням. 4.Як за один прохід знайти найкращий день купити й найкращий продати акції?
Під час проходу масиву потрібно відстежувати мінімальну ціну з побачених (⁠minPrice⁠) і для кожного дня розраховувати потенційний прибуток (ціна мінус ⁠minPrice⁠), оновлюючи максимальний прибуток на льоту. 5.Тисяча запитів «яка сума чисел з 10-го по 1000-й?» — як відповідати миттєво?
Використати масив префіксних сум (prefix sums). Попередньо порахувавши суми за O(n), будь-який запит на діапазоні можна обчислити за миттєвий час O(1) через різницю двох префіксних сум. 6.Чи корисно вчити готові прийоми, чи вони заважають думати самому?
Готові прийоми й шаблони вкрай корисні: вони слугують надійними будівельними блоками, економлять час і звільняють ментальні ресурси для вирішення більш творчих чи складних архітектурних завдань.

1.Що насправді відбувається під час ⁠x = x + 1⁠?
Значення змінної зчитується з пам’яті в регістр процесора, арифметика додає одиницю, після чого результат записується назад у комірку пам’яті.
2.Чим ⁠=⁠ відрізняється від ⁠==⁠?
⁠=⁠ — це присвоєння значення змінній, а ⁠==⁠ — це логічне порівняння двох значень (повертає ⁠true⁠ або ⁠false⁠).
3.Коли брати ⁠while⁠, а коли ⁠for⁠?
⁠for⁠ використовується, коли заздалегідь відома кількість ітерацій або є чіткий лічильник. ⁠while⁠ застосовується, коли повторення тривають до настання певної умови, а кількість кроків невідома.
4.Чи можна написати будь-яку програму, маючи лише ⁠if⁠ і ⁠while⁠?
Так, згідно з теоремою Бьома — Якопіні, цих конструкцій достатньо для повноти за Тьюрінгом, тобто для реалізації будь-якого алгоритму.
⁠5.break⁠ посеред циклу — зручність чи поганий стиль?
Це зручний інструмент для раннього виходу (early exit) при знаходженні потрібного результату, проте зловживання ним може ускладнити читабельність коду.
6.Як переконатися, що цикл колись завершиться?
Необхідно переконатися, що змінна, яка впливає на умову завершення циклу, обов’язково змінює своє значення всередині тіла циклу на кожному кроці так, щоб наблизити виконання до виходу з нього.
